## Focus Matrix Notes

The matrix is no longer mock data.

- Data source: `api.listTasks()`
- Persistence:
  - drag updates `urgency_score` + `importance_score`
  - modal save updates title, effort, and quadrant-backed scores
- Overload handling:
  - board cap is `12`
  - search/filter determine which tasks are eligible for the board
  - extra tasks render in the overflow list below the board
- Current fallback if dense layouts still feel unstable in real browser testing:
  - reduce board cap from `12` to `8`
  - keep overflow as the canonical full task list
  - do not add a "show all on board" mode until collision-free rendering is proven
