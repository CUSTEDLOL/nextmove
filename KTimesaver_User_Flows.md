# K-Timesaver Matrix --- User Flow Document

## Onboarding

Download App → Sign in with Google → Grant Gmail & Calendar permissions
→ Connect Telegram → Initial brain dump → AI builds first schedule →
User sees today's priority task

------------------------------------------------------------------------

## Task Capture Flow

User brain dump → AI parses tasks → Matrix scoring applied → Scheduling
engine assigns time slots

------------------------------------------------------------------------

## Daily Flow

Morning: User receives Morning Brief → Sees today's main task

Daytime: Pre‑task nudge → User executes → Completion logged

Missed tasks: Automatically rescheduled

------------------------------------------------------------------------

## Procrastination Handling

Task not started → System detects inactivity → Telegram conversation →
User identifies blocker → System suggests next step

------------------------------------------------------------------------

## Weekly Intelligence

Sunday review: Completion analysis → productivity patterns → next week
schedule prepared

------------------------------------------------------------------------

## Core Interaction Principle

The user only sees:

TODAY'S ONE TASK\
+ 2--3 secondary tasks

All planning complexity is hidden.
